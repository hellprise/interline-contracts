# What is this

This is a folder with initial seed data for interline contracts. Files in this folder were generated by util `cmd/seedgen` from `interline-engine`.
The command for regeneration is `go run ./cmd/seedgen -seed 42 -start 2026-11-02 -days 30 -out ../interline-contracts/seed`.

## Files and Columns

| File           | Columns                                                                                         |
| :------------- | :---------------------------------------------------------------------------------------------- |
| `airlines.csv` | `code, name`                                                                                    |
| `airports.csv` | `iata, name, country`                                                                           |
| `flights.csv`  | `flight_key, airline_code, flight_number, dep_airport, arr_airport, dep_time_utc, arr_time_utc` |

## Data rules

- **Timestamps:** UTC in `RFC 3339` format ending with `Z`.
- **Flight key (`flight_key`):** `AIRLINE-NUMBER-YYYY-MM-DD`, where the date is the UTC departure date and `flight_number` is in `1..9999`.
- **Duration & sorting:** flight block time is `45m..5h`; `flights.csv` is sorted by `dep_time_utc`, then by `flight_key`.
- **Volume & connections:** `100..2000` flights per day, with at least 20 origin-destination-date pairs per day reachable only via a single connection (`60m..12h` layover).
- **Airports & airlines:** airports use real 3-letter IATA codes (`>= 12`) and 2-letter ISO country codes; airlines (`>= 3`) use 2-character `[A-Z0-9]` codes.

Airline names and designators are fictional; any match with a real airline is coincidental.
